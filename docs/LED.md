# LED 연결과 표현

## 구성

- ESP32 GPIO18, Adafruit NeoPixel, `NEO_GRBW + NEO_KHZ800`, USB 115200 baud.
- 전체 64개: 논리 구간 1은 22개(0~21), 2는 21개(22~42), 3은 21개(43~63).
- 화면의 물리 배치는 **맨 위=구간3, 가운데=구간2, 맨 아래=구간1**입니다.
- 실제 데이터 체인의 방문 순서는 별도 확인해야 합니다. 반대 방향은 스케치의 `ROW_REVERSED`로 조정합니다.
- 최신 코드는 `firmware/emotion_wall_top3/emotion_wall_top3.ino`입니다. GitHub 업데이트와 보드 업로드는 별개입니다.

## 실제 LED 실행

Arduino IDE에서 보드 모델과 포트를 선택해 최신 코드를 업로드한 뒤 시리얼 모니터를 닫습니다.
실제 포트는 `python -m serial.tools.list_ports`로 확인합니다.

```sh
EMOTION_WALL_PORT=/dev/cu.YOUR-ACTUAL-PORT python -m uvicorn api:app --host 127.0.0.1 --port 8000 --workers 1
```

한 worker, reload 없이 실행합니다. 서버의 코드나 포트 환경변수를 바꾸면 서버도 재시작합니다.
USB 연결은 첫 전송 때 열고 서버가 종료될 때 닫습니다. 보드 분리 후 오류가 발생하면 다음 요청에서 재연결합니다.
클라우드 서버는 개인 컴퓨터의 USB를 직접 사용할 수 없으므로 `EMOTION_WALL_PORT`를 설정하지 않습니다.

## 감정과 속도

`emotion_ranked.build_motion()`이 모든 출력에 사용할 계획을 만듭니다.
상위 감정색은 `neutral`을 제외하고 선택합니다. `neutral`은 뚜렷한 감정 없음의 모델 분류입니다.
감정색이 부족하면 대표색을 반복하며, 감정이 없으면 기본 앰버를 사용합니다.

- 맨 위·가운데: 대표 감정색. 전체 이동 주기 0.9~6초.
- 맨 아래: 상위 세 감정색. 이동 주기 0.6~2.4초.
- 감정 비율과 강도(`intensity`)에 따라 격한 감정은 빠르게, 차분한 감정은 느리게 흐릅니다.
- 현재 최대 채널값은 96/255, 한 LED의 RGBW 채널 합은 160 이하이며 W 혼합은 하지 않습니다.

이 값은 소프트웨어 PWM 한도이며 전류 측정·보호 장치가 아닙니다.
LED는 적합한 외부 전원과 ESP32 공통 GND가 필요합니다. 전압·전류·배선 정격을 확인하고 전원을 끄고 배선하세요.
120개 등 다른 LED 수를 전제로 한 이전 실험용 스케치는 현재 배포 대상이 아닙니다.

## USB 명령

| 명령 (끝에 개행) | 적용 |
|---|---|
| `PING` | `READY` 응답 |
| `R,G,B,W` | 모든 구간의 목표색 설정. TOP 모드 해제 |
| `SPEED,ms` | 모든 구간의 이동 주기. 900~6000ms |
| `ROW,번호,R,G,B,W,ms` | 한 구간의 색·속도. 번호 1~3 |
| `TOP,R1,G1,B1,R2,G2,B2,R3,G3,B3,ms` | 구간1의 세 색 팔레트. 600~2400ms |

각 명령은 `OK,...` 또는 `ERR,...`를 반환합니다. API는 TOP → ROW2 → ROW3 응답을 모두 받아야 `led.sent=true`입니다.
부분 실패 시 이미 전송한 구간은 유지될 수 있습니다. ACK는 수신 확인이며 발광이나 배선 정상 여부를 보장하지 않습니다.
0,0,0,0은 약 2.6초에 걸쳐 소등합니다. 연결 해제만으로는 자동 소등하지 않습니다.

## 웹 표현은 실제 발광의 측정값이 아닙니다

차트는 부드러운 별도 팔레트, LED 명령은 선명한 RGBW 팔레트를 사용합니다.
말랑이 3×4는 같은 감정 팔레트를 반투명하게 표현하며, 맨 아래 행은 **독립적인 12초 주기**로 움직입니다.
웹 LED 예시는 계산된 실제 이동 주기를 표시합니다. 웹의 색 혼합은 RGB, 보드의 색 혼합은 HSV여서 중간색은 다를 수 있습니다.
재생·멈추기와 OS 움직임 줄이기 설정은 말랑이·웹 예시에만 적용됩니다. 말랑이 터치는 눌림 효과만 제공합니다.
웹 미리보기는 실제 LED의 밝기·방향·전환 위상과 동기화된 화면이 아닙니다.
